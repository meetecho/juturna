How-to guides
=============

These guides are recipes: each one takes you through a task you are likely to
meet when working with Juturna. They assume you know the basics; if you do
not, start from the :ref:`tutorial <tutorial>`.

- :doc:`install` Juturna and its optional groups
- :doc:`write and package a node <create_nodes>`
- :doc:`write, check and run a pipeline <create_pipelines>`
- :doc:`use environment variables <environment>` in a configuration
- :doc:`run pipelines behind an HTTP service <serve_pipelines>`
- :doc:`run a node on another machine <remotise_node>`
- :doc:`observe a pipeline <observe>`: logs, health, telemetry and files
- :doc:`build a Docker image <docker>`
- :doc:`upgrade from Juturna 2.x <migrate_from_2>`
